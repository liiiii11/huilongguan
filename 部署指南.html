一、功能概览

升级后的版本支持多账号协作使用：

  • 多用户登录：每个店员注册独立账号，邮箱+密码登录
  • 店铺管理：第一个注册的人创建店铺并成为管理员，自动获得 6 位邀请码
  • 邀请加入：其他店员通过邀请码加入同一店铺
  • 角色权限：管理员可为任意人员录入业绩、管理员工；普通员工只能以自己名义录入
  • 全店共享：所有同店成员共享业绩数据，管理员可查看全店明细与汇总
  • 数据迁移：首次登录时自动检测本地历史数据，一键迁移到云端
  • 向下兼容：未配置 Supabase 时自动降级为单机 localStorage 模式

二、创建 Supabase 项目

1
访问 supabase.com，点击「Start your project」注册（可用 GitHub 账号登录）
2
点击「New Project」，填写项目名称（如 sales-tracker），设置数据库密码（请牢记）
3
选择离你最近的区域（如 Northeast Asia - Tokyo），点击「Create new project」
4
等待 1-2 分钟，项目创建完成后进入 Dashboard
Supabase 免费版包含：500MB 数据库存储、50MB 文件存储、50000 月活用户，完全够用。

三、初始化数据库

1
在 Supabase Dashboard 左侧菜单点击「SQL Editor」
2
点击「New query」，打开项目文件夹中的 schema.sql 文件，复制全部内容粘贴到编辑器
3
点击「Run」按钮执行，看到 Success. No rows returned 即表示成功
这一步会创建所有数据表、安全策略和自动触发器。只需执行一次，请勿重复执行。

验证 Authentication 设置

4
进入 Dashboard 左侧点击「Authentication」，在上方标签页中选择「Providers」（或「Sign In / Providers」），确认 Email 已启用（开关为绿色）
5
（可选）在同一个 Email Provider 页面中，找到「Confirm email」开关，关闭它可跳过邮箱验证步骤，注册后直接登录，方便快速测试

四、配置连接信息

1
在 Dashboard 左侧点击「Settings → API」（或 Project Settings → API）
2
找到以下两项并复制：
  • Project URL：形如 https://abcdefgh.supabase.co
  • anon public key：一长串以 eyJ 开头的字符串
3
打开 assets/config.js，填入你的信息：
var SUPABASE_CONFIG = {
  url: 'https://abcdefgh.supabase.co',   // ← 替换为你的 Project URL
  anonKey: 'eyJhbGciOiJIUzI1NiIs...'     // ← 替换为你的 anon key
};
配置完成！现在可以在浏览器中打开 sales-tracker.html 测试。如果是空白页或降级为单机模式，请检查 URL 和 key 是否正确。

五、部署到线上

方式一：Netlify Drop（最快，推荐）

  1. 将整个 sales-tracker 文件夹打包为 zip
  2. 访问 app.netlify.com/drop
  3. 拖拽 zip 文件到页面中，几秒后获得 xxx.netlify.app 网址
  4. 将网址分享给店员即可使用

方式二：Vercel

  1. 访问 vercel.com 并登录
  2. 点击「New Project」，上传 sales-tracker 文件夹
  3. Framework Preset 选「Other」，点击 Deploy
  4. 获得 xxx.vercel.app 网址

方式三：GitHub Pages

  1. 在 GitHub 创建新仓库，上传 sales-tracker 全部文件
  2. 进入仓库 Settings → Pages
  3. Source 选「main」分支，保存后等待 1 分钟
  4. 获得 username.github.io/repo-name 网址
无论哪种方式，都是纯静态文件部署，无需服务器。数据全部存在 Supabase 云端数据库中。

六、使用流程

管理员（第一个注册的人）

  1. 打开应用网址，点击「注册」
  2. 输入昵称、邮箱、密码，完成注册
  3. 进入店铺设置页面，选择「创建店铺」
  4. 输入店铺名称和你的昵称，点击创建
  5. 进入主页后，点击右上角「提成类型」图标，可以看到店铺邀请码
  6. 将邀请码分享给其他店员
  7. 如果之前有本地数据，系统会提示是否迁移到云端

普通员工（被邀请的人）

  1. 打开同一个应用网址，点击「注册」
  2. 输入昵称、邮箱、密码，完成注册
  3. 进入店铺设置页面，选择「加入店铺」
  4. 输入管理员给的 6 位邀请码和你的昵称，点击加入
  5. 进入主页后即可开始记录业绩

七、常见问题

Q: 注册后提示"请检查邮箱验证"

这是 Supabase 默认的安全设置。你可以去邮箱点击验证链接，或者到 Supabase Dashboard → Authentication → Settings 中关闭「Confirm email」选项。

Q: 忘记密码怎么办？

管理员可在 Supabase Dashboard → Authentication → Users 中直接重置任意用户的密码。

Q: 如何添加更多管理员？

在 Supabase Dashboard → Table Editor → profiles 表中，将目标用户的 role 字段从 staff 改为 manager 即可。

Q: 不想用多账号，还能单机使用吗？

可以。只要 config.js 中的 url 和 anonKey 为空，应用会自动降级为 localStorage 单机模式，数据保存在本地浏览器中。

Q: 数据安全吗？

Supabase 使用 PostgreSQL 行级安全（RLS）策略，每个用户只能访问自己店铺的数据。anon key 是公开密钥，配合 RLS 使用是安全的，但绝不要在代码中放入 service_role key。

Q: 免费额度够用吗？

对于 1-5 人的小型店铺，Supabase 免费版完全够用。500MB 数据库可存储数十万条记录，50000 月活用户远超需求。
